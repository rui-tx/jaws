Coding Standards

  • Prefer Optional over nulls in APIs to avoid NPEs.
  • Follow Controller → Service → Repository with DTOs. Request DTOs validate themselves.
  • Module naming: Norse gods matching responsibilities.
  • Keep it simple. Working code first, refactor later.

Documentation

  • Each module has its own page under www/docs/.
  • Cross-link related modules at the bottom of each page.
