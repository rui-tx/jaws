Norns (Scheduler)

The Norns scheduler manages scheduled tasks in JAWS, like the cleanup of expired uploads.

1. Overview

Provides a flexible and reliable way to execute scheduled tasks in the application.

2. Features

  • Configurable scheduling using time intervals
  • Background task execution
  • Error handling and logging
  • Thread-safe operation
  • Graceful shutdown support

3. Implementation Example

private static Thread createCronService() {
    Norns norns = Norns.getInstance();
    norns.registerTask(
        "file-cleanup",
        () -> new CleanupService().cleanup(),
        5,
        TimeUnit.MINUTES
    );
    return new Thread(norns, "norns");
}

4. Error Handling

  • Logs all errors with detailed stack traces
  • Continues operation even if individual tasks fail
