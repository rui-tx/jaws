1) Core

  • URL — env: URL | prop: url | default: http://localhost:15000/
  • PORT — env: PORT | prop: port | default: 15000
  • WWW path — env: WWWPATH | prop: www.path | default: src/main/resources/www/
  • WWW blocked patterns — env: WWW_BLOCKED_PATTERNS | prop: www.blocked.patterns | default: empty (comma-separated list)
  • Custom 401 page — env: CUSTOM_PAGE_PATH_401 | prop: custom.page.path.401 | default: empty
  • Custom 404 page — env: CUSTOM_PAGE_PATH_404 | prop: custom.page.path.404 | default: empty

2) Database paths

  • Main DB path — env: DBPATH | prop: database.path | default: src/main/resources/db.db
  • Schema path — env: DBSCHEMAPATH | prop: database.schema.path | default: src/main/resources/sql/create_schema_v1.sql

3) JWT / Tyr

  • JWT secret — env: JWTTOKEN | prop: jwt.secret | default: none (auto-generated if missing)
  • Application name (issuer) — constant: JAWS (not overridden via config)

4) Hermod (templates)

  • Dev mode — env: HERMOD_DEVELOPMENT_MODE | prop: hermod.development.mode | default: false
  • Template cache TTL (ms) — env: HERMOD_TEMPLATE_CACHE_TTL | prop: hermod.template.cache.ttl | default: 3600000

5) Norns/Freyr (jobs & queue)

  • Worker threads — env: WORKER_THREADS | prop: freyr.queue.workers | default: Runtime.availableProcessors()
  • Queue capacity — env: QUEUE_CAPACITY | prop: freyr.queue.size | default: 10000
  • Cleanup interval (ms) — env: CLEANUP_INTERVAL_MS | prop: freyr.queue.interval_cleanup | default: 300000

6) JawsLogger

  • DB level — env: DB_LEVEL | prop: jawsLogger.db.level | default: INFO
  • Batch size — env: BATCH_SIZE | prop: jawslogger.batchsize | default: 1000
  • Flush interval (ms) — env: FLUSH_INTERVAL_MS | prop: jawslogger.flush_interval | default: 5000
  • Buffer capacity — env: BUFFER_CAPACITY | prop: jawsLogger.buffer_capacity | default: 10000

7) Startup barrier

  • Mimir init timeout (ms) — env: STARTUP_DB_TIMEOUT_MS | prop: startup.mimir.timeout.ms | default: 30000

8) RateLimiter

  • Max requests — env: RATE_LIMIT_MAX_REQUESTS | prop: ratelimiter.max.requests | default: 100
  • Window (ms) — env: RATE_LIMIT_WINDOW_MS | prop: ratelimiter.window.ms | default: 60000

9) Mimir Cache

  • Enabled — env: MIMIR_CACHE_ENABLED | prop: mimir.cache.enabled | default: true
  • Max size — env: MIMIR_CACHE_MAX_SIZE | prop: mimir.cache.maxSize | default: 10000

10) Mimir/Hikari (SQLite)

  • Reader pool size — env: MIMIR_READER_POOL_SIZE | prop: mimir.reader.pool.size | default: 16
  • Busy timeout (ms) — env: MIMIR_BUSY_TIMEOUT_MS | prop: mimir.busy.timeout.ms | default: 5000
  • Enable WAL — env: MIMIR_ENABLE_WAL | prop: mimir.enable.wal | default: true
  • Synchronous mode — env: MIMIR_SYNCHRONOUS_MODE | prop: mimir.synchronous.mode | default: NORMAL

Example application.properties

# Core
url=http://localhost:15000/
port=15000
www.path=src/main/resources/www/
www.blocked.patterns=
custom.page.path.401=
custom.page.path.404=

# Database paths
database.path=src/main/resources/db.db
database.schema.path=src/main/resources/sql/create_schema_v1.sql

# JWT / Tyr
jwt.secret=<paste-generated-secret>

# Hermod
hermod.development.mode=false
hermod.template.cache.ttl=3600000

# Freyr (queue)
freyr.queue.workers=4
freyr.queue.size=10000
freyr.queue.interval_cleanup=300000

# JawsLogger
jawsLogger.db.level=INFO
jawslogger.batchsize=1000
jawslogger.flush_interval=5000
jawsLogger.buffer_capacity=10000

# Startup
startup.mimir.timeout.ms=30000

# RateLimiter
ratelimiter.max.requests=100
ratelimiter.window.ms=60000

# Mimir Cache
mimir.cache.enabled=true
mimir.cache.maxSize=10000

# Mimir/Hikari
mimir.reader.pool.size=16
mimir.busy.timeout.ms=5000
mimir.enable.wal=true
mimir.synchronous.mode=NORMAL
Precedence: environment variables override properties. If no env/prop is set, defaults from ApplicationConfig apply.
