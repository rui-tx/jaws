Huginn (Server-Sent Events)

Huginn is JAWS' SSE hub. Clients subscribe to a channel, and the server can broadcast events to all subscribers or filter delivery by roles or specific users.

Client subscription

The backoffice layout wires SSE via HTML attributes: 

<body sse-connect="/events" sse-swap="notification">
  <!-- ... -->
  <div id="toaster"></div>
</body>

Event types

Event names are typed via Huginn.EventType. Currently:

  • NOTIFICATION → event name notification

Server-side broadcasting

ToastNotifier is just and example. Use ToastNotifier to render a toast (Thymeleaf fragment) and broadcast. 

// Broadcast to all subscribers on the channel
ToastNotifier.broadcastToast("Build complete", "Artifacts published.");

// Broadcast only to specific roles
ToastNotifier.broadcastToast(Set.of("admin"), "Maintenance", "DB migration at 22:00");

// Broadcast only to a specific user (by userId)
ToastNotifier.broadcastToast(userId, "Report ready", "Your export finished.");

Under the hood, ToastNotifier uses Huginn:

  • broadcast(String channel, EventType event, String data)
  • broadcastToRoles(String channel, Set<String> roles, EventType event, String data)
  • broadcastToUser(String channel, String userId, EventType event, String data)

Notes

  • Multiple audiences can share the same channel (e.g., admins and users).
  • Per-event filtering ensures only eligible clients receive a given event.
  • Use role/user-filtered helpers for sensitive messages.
