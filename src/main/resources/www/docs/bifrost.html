Bifrost (Middleware)

On this section
  • Overview
  • Key Middlewares
  • Usage

Bifrost is the middleware system that processes requests before they reach controllers and responses before they are sent.

Overview

Middleware are executed in order. Each may short-circuit the chain.

Key Middlewares

  • LoggingMiddleware — request/response logging
  • CorsMiddleware — CORS headers
  • AuthMiddleware — JWT validation for protected routes

Usage

// register in startup order
// e.g., logging -> cors -> auth
Ensure middlewares are idempotent and fast; avoid blocking operations.
